# Studio Marczoff : politique de confidentialité

Studio Marczoff est un outil personnel qui dépose des vidéos dans les brouillons TikTok de son propriétaire.

- Données utilisées : le jeton d'accès TikTok du propriétaire et son identifiant public de compte. Aucune autre donnée n'est lue.
- Le jeton est conservé chiffré et sert uniquement à déposer les vidéos en brouillon.
- Aucune donnée n'est vendue, partagée ou utilisée à des fins publicitaires.
- Aucune donnée d'autres utilisateurs de TikTok n'est collectée.
- Pour retirer l'accès : réglages du compte TikTok, applications autorisées. Le jeton devient alors inutilisable.
